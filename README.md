# P2P Chat Application

A high-performance peer-to-peer communication suite built with Python. Designed for low-latency message transmission across local networks.

## 🛠 Tech Stack
* **Language:** Python 3.11
* **Framework:** Kivy / KivyMD (UI)
* **Networking:** Socket Programming (TCP/IP)
* **Build Tools:** Buildozer (Android Deployment)

## 🚀 Key Features
* **Real-time Communication:** Direct P2P data exchange without a central server relay.
* **Responsive UI:** Adaptive interface using Material Design principles.
* **Cross-Platform Ready:** Compiles to native Android APKs.

## 📁 Repository Structure  
/client       # Frontend mobile logic  
/server       # Backend socket handling logic  
/bin          # Compiled release artifacts  


## 📜 Setup Instructions
1. Clone the repo: `git clone [url]`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the server: `python server/server.py`
